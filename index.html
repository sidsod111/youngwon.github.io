2. 주요 기능 명세

자기소개 섹션
프로필 사진, 이름, 학교·학과, 희망 직무(반도체), 한 줄 소개, 핵심 역량 태그 표시
  • 드론조종사 자격증 2종 강조
  • 검소절약상(봉사상) 수상 표기
  • 인공지능 기초 우수 성적(1학기 A) 강조
주요 활동 섹션
교내외 활동을 카드형으로 나열. 학년/학기별 필터 가능
  • 1학년 학급 회장 활동
  • 전자기기응용하드웨어개발연구반 동아리
  • 봉사활동(환경 보호, 교내 청결, 캠페인)
  • 하쿠나마타나 봉사동아리 (2학년)
프로젝트 경험 섹션
프로젝트 카드에 제목·기간·사용 기술·결과물 사진/영상 첨부
  • 드론콘텐츠 제작 (비행 시나리오, 영상)
  • 3D 프린터 제품 제작 (모델링·출력)
  • 로봇 소프트웨어 개발 (센서·코드)
  • 유선통신 구축 (설계도·시공)
  • 가전기기 시스템 소프트웨어 개발
자격증 · 역량 섹션
취득 자격증 및 NCS 이수 현황을 시각적으로 표시
  • 초경량비행장치조종사 (멀티콥터 4종)
  • 초경량비행장치조종사 (헬리콥터 4종)
  • NCS 이수 12개 능력단위 목록
  • 성취도 A 항목 하이라이트
미디어 갤러리
작품 사진 그리드 + 동영상 임베드 전용 영역
  • 사진: 다중 이미지 업로드·썸네일 그리드
  • 동영상: YouTube/직접 업로드 URL 임베드
  • 클릭 시 라이트박스 전체화면 보기
  • 카테고리 태그(드론·3D·로봇 등) 필터
연락처 섹션
채용 담당자가 쉽게 연락할 수 있는 정보 표시
  • 이메일·전화번호 표시
  • 문의 폼 (이름·연락처·메시지)
  • GitHub·SNS 링크 (선택)

3. 관리자 기능

로그인 후 모든 섹션의 텍스트·사진·동영상을 직접 수정할 수 있습니다.
초기 계정 — 아이디: qwer1234 / 비밀번호: qwer1234

관리자 패널 기능 목록

  • 로그인/로그아웃 (세션 유지)
  • 자기소개 텍스트·프로필 사진 수정
  • 활동 카드 추가·수정·삭제 (CRUD)
  • 프로젝트 카드 추가·수정·삭제 (CRUD)
  • 갤러리 사진 업로드·삭제
  • 동영상 URL 등록·수정·삭제
  • 연락처 정보 수정
  • 비밀번호 변경 기능

4. 기능 우선순위

기능 우선순위 근거 (생기부 기반)
자기소개 + 자격증 표시 높음 드론 자격증 2종, 반도체 희망직종 — 채용담당자 첫인상
프로젝트 경험 카드 높음 드론·3D·로봇·통신 다양한 실습 프로젝트 다수 보유
미디어 갤러리 (사진) 높음 3D 출력물·드론 영상 등 시각 자료 풍부
관리자 로그인·편집 높음 수시 업데이트 필요 (자격증 추가 가능성)
주요 활동 섹션 중간 학급회장·동아리·봉사 — 인성 강조
동영상 임베드 중간 드론 촬영 영상 보유 가능성 있음
연락처·문의 폼 중간 채용 담당자 연락 경로 필수
SNS·GitHub 연동 낮음 현재 생기부에 미기재, 추후 추가 가능

5. 비기능 요구사항

반응형 디자인
PC, 태블릿, 스마트폰 모두에서 동일하게 보여야 함. 모바일 채용 담당자 고려.
빠른 로딩
이미지 최적화 및 lazy loading 적용. 3초 이내 첫 화면 표시 목표.
보안
관리자 비밀번호 해시 저장. 로그인 없이 편집 불가. 초기 비밀번호 변경 권장.
접근성
이미지 alt 텍스트 필수 입력. 키보드 탐색 지원. 충분한 색상 대비.

6. 콘텐츠 초안 — 생기부 기반

자기소개 초안

드론 조종 자격증 2종(멀티콥터·헬리콥터)을 보유한 전자융합과 학생으로, 3D 모델링부터 로봇 소프트웨어 개발, 유선통신 구축까지 폭넓은 실무 경험을 쌓았습니다. 반도체 분야 전문가를 목표로 관련 이론과 기술을 꾸준히 학습 중이며, 끝까지 포기하지 않는 도전 정신과 팀원과의 협업 능력을 강점으로 삼고 있습니다.
위 초안은 생기부 내용을 바탕으로 자동 생성된 예시입니다. 웹사이트 완성 후 관리자 패널에서 직접 수정해 주세요.
